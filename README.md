# 📚 Estrutura de Dados e Algoritmos (EDA)

Repositório dedicado aos meus estudos de **Estrutura de Dados e Algoritmos**, com foco em resolução de problemas de plataformas como:

- 🟡 LeetCode
- 🔵 MOJ (Beecrowd / URI)
- 🟢 Exercícios da disciplina de EDA

---

## 🎯 Objetivo

Este repositório tem como objetivo:

- Praticar lógica de programação
- Aprender e aplicar estruturas de dados
- Melhorar desempenho em algoritmos
- Preparação para provas e entrevistas técnicas

---

## 🧠 Conteúdos abordados

- Arrays e Strings
- Listas Ligadas
- Pilhas e Filas
- Árvores
- Hash Tables
- Recursão
- Busca Binária
- Ordenação
- Grafos (em andamento)
